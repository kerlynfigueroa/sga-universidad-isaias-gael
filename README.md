# Sistema de Gestión Académica (SGA)

## Caso de Estudio: Universidad Isaías Gael

## Descripción

Sistema de Gestión Académica desarrollado como proyecto para la asignatura Arquitectura de Software.

La aplicación permite gestionar de manera integrada los procesos académicos de una institución de educación superior, incluyendo la administración de estudiantes, docentes, asignaturas, matrículas, tutorías, calificaciones, reportes y certificados.

El proyecto fue diseñado utilizando principios de Arquitectura de Software y apoyado mediante herramientas de Inteligencia Artificial, particularmente Google AI Studio.

---

## Objetivo General

Diseñar e implementar un Sistema de Gestión Académica que permita administrar los procesos académicos institucionales de manera eficiente, centralizada y organizada.

---

## Objetivos Específicos

- Gestionar la información de estudiantes y docentes.
- Administrar asignaturas y programas académicos.
- Registrar matrículas académicas.
- Gestionar procesos de evaluación y calificaciones.
- Administrar tutorías académicas.
- Generar reportes y certificados.
- Aplicar principios de Arquitectura de Software en el diseño e implementación del sistema.
- Utilizar herramientas de Inteligencia Artificial para apoyar el proceso de desarrollo.

---

## Arquitectura del Sistema

El sistema fue diseñado utilizando una Arquitectura por Capas.

### Capa de Presentación

Encargada de la interacción con los usuarios mediante interfaces web responsivas.

### Capa de Lógica de Negocio

Implementa reglas académicas, validaciones y procesos institucionales.

### Capa de Datos

Gestiona el almacenamiento y recuperación de información utilizando LocalStorage para la persistencia de datos en el prototipo.
